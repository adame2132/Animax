# Animax

## Description

**Animax** is an anime-style streaming application that utilizes the iOS application sandbox and property lists (plists) to present sections of popular anime titles. The app showcases detailed information for each anime, including descriptions and episode counts. Animax features three main controller modes: a homepage displaying a curated selection of anime, a detailed view for exploring individual titles, and a "Watch Later" view that allows users to add randomly selected anime to a personalized watchlist.
